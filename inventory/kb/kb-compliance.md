# 多平台上架合规红线速查

## 通用三条

1. **不得诱导站外交易**。几乎所有开放平台（微信、抖音、支付宝、快手）都禁止在插件内引导用户跳转到外部支付或私域成交，会被下架甚至封号。变现要走平台自身的交易组件或你所售服务本身的定价，不要写"加微信""扫码付款"。
2. **不得二次分发用户数据**。插件拿到的用户输入只能用于当次服务，不得留存转卖。
3. **AI 生成内容要有标识**。国内生成式 AI 服务需按规定标识 AI 生成内容，纯工具类（如代码格式化）可豁免。

## 分平台要点

| 平台 | 变现可行性 | 关键限制 |
|---|---|---|
| 微信小程序 | 虚拟支付仅支持 Android，iOS 走不了 | iOS 端不要放付费入口 |
| 抖音小程序 | 需企业主体 + 类目资质 | 个人开发者不能上付费类目 |
| 支付宝小程序 | 支持，需签约 | 收款走支付宝商家账户 |
| Coze / 扣子 | 插件本身不能直接收 C 端钱 | 收费在"Bot 付费/知识付费"侧，插件做能力 |
| 钉钉应用市场 | 支持按席位/按年 | 需企业认证，个人上不了 |
| npm / GitHub | 无平台内收款 | 只能引流自有站点结算 |
| MCP 市场（Smithery 等） | 多数不托管收款 | 走 x402 或自带 key |

## 极限词与功效宣称

广告法禁用：国家级、最高级、最佳、第一、首款、独家、根治、特效、永久。
功效类产品不得承诺疗效。写"使用感受"不写"治疗效果"。

## 商用授权怎么举证

给买方签发带 HMAC 签名的授权凭证（含 SKU、买方、授权范围、有效期、签名），
买方离线可验。出现争议或平台申诉时，凭证就是证据链。
